    - question: 'What is BulkPixel?'
      answer: 'BulkPixel is a focused, local-first macOS app and command-line tool for converting, resizing, renaming, and exporting multiple images in one workflow.'
    - question: 'Is BulkPixel free and open source?'
      answer: 'Yes. BulkPixel is free to use and its source code is available on GitHub under the MIT license.'
    - question: 'Which image formats does BulkPixel support?'
      answer: 'BulkPixel supports JPG, JPEG, PNG, WEBP, and AVIF input. It can export image batches as JPEG, PNG, WEBP, or AVIF.'
    - question: 'Can BulkPixel resize multiple images at once?'
      answer: 'Yes. BulkPixel can resize an entire image batch by width or height while preserving the original aspect ratio.'
    - question: 'Does BulkPixel process images locally?'
      answer: 'Yes. Image conversion runs locally on your Mac. BulkPixel does not require an account or upload your image files to a cloud service.'
    - question: 'What are BulkPixel presets?'
      answer: 'Presets save format, dimensions, quality, filename settings, and the output folder so the same export workflow can be reused in the desktop app or CLI.'
    - question: 'What are Magic Directories in BulkPixel?'
      answer: 'Magic Directories watch selected folders while BulkPixel is running. When a matching image is added, BulkPixel automatically applies one or more selected presets.'
    - question: 'What does BulkPixel Statistics show?'
      answer: 'Statistics shows conversion totals by format, input and output storage, saved space, processing time, and the dates of the first and latest conversion.'
    - question: 'Does BulkPixel remove EXIF metadata and protect existing files?'
      answer: 'BulkPixel can remove EXIF metadata during export and uses collision-safe filenames to avoid accidentally overwriting existing files.'
    - question: 'Can I use BulkPixel from the command line?'
      answer: 'Yes. BulkPixel includes a CLI for conversions, presets, and statistics. The app and CLI can be installed together with Homebrew on macOS.'
