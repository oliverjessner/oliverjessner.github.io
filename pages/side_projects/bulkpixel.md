faq:
    - question: 'Is BulkPixel free?'
      answer: 'Yes. BulkPixel is free and open source under the MIT license.'
    - question: 'Does BulkPixel work offline?'
      answer: 'Yes. Local files can be converted offline. Importing images from URLs requires an internet connection; conversion still runs locally on your Mac without uploading images to a conversion service.'
    - question: 'Can BulkPixel import images from URLs?'
      answer: 'Yes. Add from URL accepts public image and website URLs, one per line. Cmd+V outside a text field opens the dialog with clipboard URLs. Click Import Images to start. The CLI supports --url. Images requiring login cookies are not supported.'
    - question: 'Which image formats does BulkPixel support?'
      answer: 'Import JPEG, PNG, WebP, AVIF, SVG, HEIC/HEIF, TIFF, GIF, JPEG XL, JPEG 2000 and ICO. Export JPEG, PNG, WebP and AVIF. The app, CLI and Watched Folders share this support.'
    - question: 'Can BulkPixel keep animation or every TIFF page?'
      answer: 'No. Animated GIF and JPEG XL files export the first frame as a still image. Multipage TIFF files export the first page. Choose PNG, WebP or AVIF to preserve transparency; JPEG uses a white background.'
    - question: 'Can BulkPixel convert HEIC images?'
      answer: 'Yes. BulkPixel can import HEIC and HEIF images on macOS and convert them to JPEG, PNG, WebP, or AVIF.'
    - question: 'Can BulkPixel convert ICO files?'
      answer: 'Yes. BulkPixel imports ICO files and converts them to JPEG, PNG, WebP, or AVIF in the desktop app, CLI, and Watched Folders. For icons containing multiple images, it selects the highest color depth, then the largest dimensions at that depth, and converts one image per file.'
    - question: 'Can BulkPixel convert multiple images at once?'
      answer: 'Yes. BulkPixel is designed for batch image conversion and applies the selected output settings to every image in the batch.'
    - question: 'Can BulkPixel resize multiple images?'
      answer: 'Yes. You can define either a target width or height, and BulkPixel automatically preserves the aspect ratio.'
    - question: 'Can BulkPixel automatically convert new images in a folder?'
      answer: 'Yes. Watched Folders can apply saved Presets automatically when matching files are added while BulkPixel is running.'
    - question: 'Does BulkPixel have a command-line interface?'
      answer: 'Yes. BulkPixel includes a `bulkpixel` CLI for conversions, Presets, Watched Folders, and statistics.'
    - question: 'Will BulkPixel overwrite my original images?'
      answer: 'Exports go to your selected output folder. The desktop app adds numbered suffixes for filename collisions. The CLI refuses existing output files unless you explicitly pass `--overwrite`. Keep exports in a separate folder when you want originals and results side by side.'
    - question: 'What happens when a Watched Folder output already exists?'
      answer: 'By default, BulkPixel keeps the existing file and numbers the new output. Each rule can explicitly enable overwriting. Watched Folders work while the desktop app is running and do not watch subfolders.'
    - question: 'How do I send an image from my browser?'
      answer: 'Load the bundled extension and connect it using the browser setup guide. Then right-click an image and choose Send to BulkPixel. Chrome, Chromium, Brave and Edge on macOS are supported; the extension is not automatically installed from a browser store.'
    - question: 'Which Macs and macOS versions does the current download support?'
      answer: 'The current download requires macOS 26 or later and Apple Silicon, starting with M1. It is not an Intel or universal Mac package.'
    - question: 'Does BulkPixel work on Windows or Linux?'
      answer: 'No. BulkPixel currently targets macOS.'
