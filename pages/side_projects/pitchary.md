    - question: 'What does folder watching import?'

    - question: 'What can the MCP integration change?'
      answer: 'It can search for and create customers, contacts and services. Editing, archiving and deleting remain actions in the app. MCP does not change proposals or financial data.'
    - question: 'Is there a CLI?'
      answer: 'The repository provides local commands for running and setting up Pitchary, plus an MCP server. A general end-user CLI for CRM management is not available.'
    - question: 'Does Pitchary cost anything?'
      answer: 'Pitchary is free and released under the MIT license. If you enable optional OpenAI recognition, you use your own API access and pay its associated costs.'
