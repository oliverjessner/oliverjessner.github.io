Mindestanzahl an Teilnahmen

Die Verlosung findet nur statt, wenn bis zum Teilnahmeschluss insgesamt mindestens {{ giveaway.minimum_entries }} gültige Teilnahmen über alle teilnehmenden Plattformen zusammen eingegangen sind.

Dabei zählen gültige Teilnahmen und nicht die reine Anzahl der abgegebenen Kommentare.

Mehrere Kommentare derselben Person auf derselben Plattform zählen daher weiterhin nur im Rahmen der zulässigen Anzahl an Teilnahmen.

Wird die Mindestanzahl von {{ giveaway.minimum_entries }} gültigen Teilnahmen nicht erreicht, findet keine Verlosung statt.

Teilnahmeberechtigung

Teilnahmeberechtigt sind natürliche Personen ab {{ giveaway.minimum_age }} Jahren mit Wohnsitz in {% for country in giveaway.eligible_countries %} {% if forloop.first %} {{ country }} {% elsif forloop.last %} oder {{ country }} {% else %} , {{ country }} {% endif %} {% endfor %}.

Die Teilnahme ist kostenlos und nicht an einen Kauf gebunden.

Auslosung

Nach Ende des Gewinnspiels werden alle gültigen Teilnahmen der teilnehmenden Plattformen in einem gemeinsamen Teilnehmerpool zusammengeführt.

Der Gewinner wird nach dem Zufallsprinzip aus allen gültigen Teilnahmen ausgelost.

Eine Teilnahme auf mehreren Plattformen erhöht entsprechend die statistische Gewinnchance.

Benachrichtigung des Gewinners

Der Gewinner wird nach der Auslosung über die Social-Media-Plattform kontaktiert, über die die gezogene Teilnahme erfolgt ist.

Der Gewinner muss innerhalb von {{ giveaway.winner_response_hours }} Stunden auf die Nachricht reagieren.

Erfolgt innerhalb dieser Frist keine Rückmeldung, kann der Gewinn neu ausgelost werden.

Ausschluss von der Verlosung

Teilnehmer können ausgeschlossen werden, wenn sie versuchen, die Verlosung technisch oder organisatorisch zu manipulieren.

  • falsche Identitätsangaben
  • sonstige Manipulationsversuche
