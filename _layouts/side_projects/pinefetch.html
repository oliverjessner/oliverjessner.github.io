Features

Choose what to save. Keep track of the rest.

Video and audio

Download through yt-dlp from supported links on YouTube, TikTok, Instagram, Facebook, Twitch and X. Availability depends on the video and platform.

Choose Best or Max 1080p video, or export MP3 or Opus audio. A supported timestamp in a link can start a download from that point. Set the output folder in PineFetch.

Captions and transcripts

For Instagram posts, an optional setting saves an available post caption beside the download as .caption.txt. This is the post description, not spoken audio.

For speech, faster-whisper creates a local TXT transcript, with or without segment timestamps. Pick a transcription quality to balance speed and accuracy, and choose whether to keep the video too.

Queue and history

Add several links, watch their progress, and use automatic start or hold the queue until you start it. Import YouTube, TikTok and Instagram links from a TXT file; PineFetch skips invalid lines and duplicates already in that file or queue.

Magic Import reads a supported URL from your clipboard when you click the PineFetch logo with an empty URL field. Local History keeps completed downloads and totals for count, file size and runtime. Logs are available in Settings when you need to diagnose a problem.

Browser and command line

PineFetch Link Dump sends single links or supported collections from Chrome to the app. Browser import accepts YouTube, TikTok and Instagram links. Its local Link Dump API also accepts links from scripts and other tools.

The included CLI adds or lists queue items and reads History and statistics. It connects to the desktop app, starting it when needed. See the CLI documentation for commands.

Get PineFetch

Install PineFetch

The current macOS release is for Apple Silicon and requires macOS Big Sur or newer.

With Homebrew

Install the app, then install yt-dlp separately. The PineFetch cask also makes its CLI command available.

brew install --cask oliverjessner/tap/pinefetch brew install yt-dlp

Need Homebrew? See its installation guide.

Download the app

Get the DMG from the current release. Install yt-dlp separately, then choose your output folder in Settings. If PineFetch cannot find yt-dlp, set its path there.

Release notes and download assets

The release bundles ffmpeg/ffprobe, Deno and the faster-whisper runtime. A transcription model may need to download before first use. Files and History are stored locally; downloads and initial model setup need an internet connection.

Made by Oliver Jessner. Download only content you own or have permission to save, and follow platform terms.
