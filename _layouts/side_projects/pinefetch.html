Setup in 60 seconds

PineFetch uses yt-dlp locally. Install the command-line dependencies once, download the app, then choose where your files should land.

Install checklist

  1. Install Homebrew if it is not already on your Mac. /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Install dependencies: brew install yt-dlp ffmpeg yt-dlp is required. ffmpeg and ffprobe are recommended for audio and video processing.
  3. Install PineFetch: brew install --cask oliverjessner/tap/pinefetch --cask tells Homebrew that PineFetch is a macOS desktop app rather than a command-line package. Homebrew downloads the app and places PineFetch.app in your Applications folder. Prefer a manual install? Use the download button above instead.
  4. Choose your download folder and start queueing links.

PineFetch finds yt-dlp automatically when it is in your PATH. Otherwise, set the full path in Settings.
