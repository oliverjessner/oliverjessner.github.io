01 / Feed

Read RSS and Atom feeds in order.

See what is new. Decide what matters. Move on.

  • Chronological means chronological. No ranking algorithm decides what should be important.
  • Search articles and filter by topic, source or reading list.
  • Switch between card and compact layouts.
  • Save, dismiss or open the original article directly.
02 / Digest

Daily, weekly and monthly RSS digests.

Related coverage from multiple sources becomes one readable story cluster.

  • See which sources covered the same event.
  • Choose a daily, weekly or monthly view.
  • Save a story or mark it as digested.
Multiple sourcesDaily / Weekly / MonthlySave storyMark as digested

This is organization, not an AI-generated summary feed. The Digest clusters articles already stored in your reader.

03 / Watchdog

Keyword alerts with Watchdog.

Your keywords. A local inbox for every match.

  • Match any keyword, require all keywords or exclude phrases.
  • Check titles, teasers and stored content.
  • Monitor all feeds or selected sources.
Keyword rulesLocal inboxRead / Archive / ExportOptional macOS alerts

Notifications are opt-in and need macOS permission. Watchdog checks with RSS refreshes while the app runs, even with its window closed. Quitting the app stops monitoring.

Read Watchdog documentation →
04 / Local topics

Local topic tags and content filters.

Topic detection without sending your feed away.

Set strong, medium and weak keywords. Matching articles receive local topic tags.

  • Edit keywords and reclassify your existing library.
  • Exclude unwanted coverage from Digest with Bullshit rules.
  • Choose Bullshit: Clean to hide those articles in Feed too.

Source control

Add and manage RSS or Atom sources.

  • Add a feed URL under Settings → RSS Feeds.
  • Test, edit or remove sources and see their stored article counts.
  • Use fetch now or automatic updates while the app runs.
05 / Publisher rankings

Most read, most commented and editor picks.

Browse saved selections from Golem, WinFuture, ComputerBase, heise iX, t3n, TechCrunch, Ars Technica, WIRED and The Verge.

  • Choose one publisher or a combined view with duplicate URLs removed.
  • Keep each publisher’s selection labels. Editorial picks remain editorial picks.
  • Updates run every eight hours while the app runs, or when you choose Refresh.

Add the publisher’s RSS feed first. Available lists vary; some sources need browser rendering. If an update fails, the last saved selection stays available.

Input, output and limits

Import article links. Export your research.

Input

Links beyond your feeds

Paste article URLs or open a plain text link list. Feed subscriptions are added separately in Settings → RSS Feeds.

Output

Four export formats

Export Feed, Digest or Watchdog results as Markdown, JSON, CSV or a link list. Active Feed and Watchdog filters are preserved.

Limits

Publisher access still matters

Feeds and article imports depend on the publisher’s response. Access restrictions and changed pages can prevent an update.

CLI and automation

Query your RSS library from the terminal.

Read saved articles, publisher selections, digests and statistics. These queries open SQLite read-only. They do not fetch feeds or start the app.

NO-BULLSHIT-RSS — read-only queries
$ no-bullshit-rss articles last 10 --url --title $ no-bullshit-rss articles top --medium t3n --json $ no-bullshit-rss articles digest 10 --weekly $ no-bullshit-rss stats --json $ no-bullshit-rss articles last 10 --url --title | grep Nvidia

Interactive selection

Discovers the existing app database on macOS.

Watchdog management can make changes.

  • Explicit commands create, edit or delete rules and change match states or notification settings.
  • These changes need the running desktop app. Reading an existing library does not.
  • The CLI does not fetch RSS feeds, run migrations or start the app.

Integrations

Connect your saved library over MCP.

Let an MCP client read stored articles, digests, reading lists, statistics and Watchdog matches.

  • Use no-bullshit-rss mcp as a stdio server in your client’s configuration.
  • MCP access is read-only. It cannot change rules, mark matches read or fetch new feeds.
  • Set up the app’s library first. Existing data can be read with the desktop app closed.

Privacy and local data

Your library stays on your Mac.

Stored locally

Feeds and reading lists

Articles, sources and reading lists live in a local SQLite database. No reader account is required.

Processed locally

Your keywords do the work

Topic detection and Watchdog use local rules. Articles are not sent to an external classification API.

Network access

Updates contact publishers

Downloads, feed refreshes, link imports and publisher rankings need internet access. MCP clients handle returned text according to their own settings.
